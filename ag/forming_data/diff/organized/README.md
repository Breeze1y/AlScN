# Diff 测试数据整理结果

原始 CSV 保留在上一级各材料/厚度目录中。本目录提供可筛选的规范化副本和汇总。

## 文件

- `device_summary.csv`：每种材料/厚度一行，列出循环数、扫描段数和点数。
- `cycle_summary.csv`：每器件每圈一行，汇总负向和正向扫描的电流范围、峰值及转折点。
- `all_iv_points.csv`：逐点长表，可按材料、厚度、循环、正/负扫描及正扫/回扫筛选。
- `iv_overview.svg`：按器件分面展示各偏压下 |I1| 的跨圈中位数；阴影为第 25–75 百分位，纵轴为对数尺度。
- `organize_diff_data.py`：使用 Python 标准库从原始文件重新生成以上文件。

## 口径

- 每个原始 CSV 按 `Analysis.Setup.Title` 识别 `IV Sweep -` 和 `IV Sweep +`。文件内相邻的一负一扫描和一正向扫描组成一圈，圈号按文件顺序从 1 开始。
- 每个扫描段有 202 个测量点。按 V1 的方向变化将其分成 `forward` 与 `return` 两段，转折电压的平台点归入 `forward`，每个原始测量点只保留一次。
- 逐点表保留原始 V1、I1、辅助电流、G 和 G1 数值。`aux_current_name` 标记辅助电流原始列名（负向为 I0，正向为 I）。G/G1 保留为原始值，不统一赋予物理单位或含义。
- `cycle_summary.csv` 中电流指标基于有符号 I1；图中使用 |I1|。没有根据阈值推断 SET/RESET 或高低阻态。
- 电压范围依原始测量设置保留：所有负向扫描到 -1.5 V；20/40 nm 正向扫描到 +1.5 V，60 nm 正向扫描到 +5.0 V。总览图使用 -1.5 至 +5.0 V 的共同横轴，未测量区间为空白。
- `device_label` 根据原始文件夹的材料与厚度生成，不是仪器序列号。
