# nature_data_batch 特征复核

## 已提取

- SET 文件：681；RESET 文件：679；R-read 文件：1807；I/V-t sampling 文件：14。
- 目录内按括号编号出现唯一 SET 与唯一 RESET 的候选编号：679 个。
- 按同目录事件时间链接到 SET 后/RESET 后阶段的读取文件：1526 个；阶段标签保留为操作前后关系，不预设HRS/LRS。
- 已将同一测试段内的SET后`R-read(2)`和RESET后即时`R-read(1)(1)`配成679条逐循环读态记录；其中482条读电压一致可算HRS/LRS比，432条达到旧方案暂定的20倍两态对比线，358条同时未触发段内MAD/整体漂移复核，作为暂定稳定标定候选。
- 按用户提供的批次标识`nature_data_batch`汇总，不要求单器件编号；不同目录/测试段仍分开保留，不能据此拼造跨段连续寿命。
- 14条 I/V-t 轨迹中，首末5%电阻中位数相差超过3倍、需查看完整时序的有 4 条；均保留，未作为噪声剔除。
- 文件名计数器发生回退时，按时间戳切分为目录内推定运行段；共 16 段，不把它们外推为跨目录连续测试历史。
- B1500 原始配置中的主通道合规值、偏置合规值、扫描起止/步进、保持/延迟及采样参数已提取到 `file_features.csv` 和 `instrument_parameter_summary.csv`；设置值与实测峰值分开保留。
- 每个文件的电压、电流峰值和端点、R 列或按 |V1/I1| 派生的电阻范围、读文件协议和文件名时间已写入 `file_features.csv`。
- SET/RESET 编号配对结果在 `cycle_pair_audit.csv`；读取电阻按读取协议独立汇总在 `read_cycle_features.csv`。
- 同目录或明确的`R/<条件>`兄弟目录内，可按导出时间把读取点标注为 SET 后/RESET 后；映射表与按阶段汇总在 `read_state_context.csv`、`read_state_summary.csv`。这些是读点所在的操作阶段，不自动改名为HRS/LRS。
- `cycle_read_state_features.csv`按测试段配对读电阻，分别保留SET后、RESET后即时及RESET后较晚的读点，并输出两态对比、段内离群/漂移复核标记。MAD与20倍阈值用于候选筛查；完整数据及所有标记均保留，未静默删除循环。
- `time_sampling_features.csv` 记录长时采样跨度、首末电阻和 log-log 漂移斜率；`time_sampling_transition_review.csv` 标出首末5%中位电阻相差超过3倍的轨迹，保留这些轨迹供状态变化复核，不按噪声删除。图片只用于数据巡检。

## 解释限制

这些编号来自文件名，目录内运行段由编号回退推断。`batch_id`是本次整理的批次标签，不是仪器序列号；目录之间的前后顺序不全，故仍不拼成一条连续寿命序列。B1500 配置中的主通道合规值已读出，但被测电流是否触及限值须逐条结合波形判断；Bias compliance 保持原多通道字符串，不把它误当成主通道限值。读取协议名称分开保留；HRS/LRS候选只依据操作后阶段和匹配读偏压标记。时间采样图使用仪器导出的Time与R列，不替代温度、环境或样品状态元数据。
