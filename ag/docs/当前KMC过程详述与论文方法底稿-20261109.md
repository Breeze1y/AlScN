# Ag/AlN/AlScN/AlN/Pt 当前 KMC 过程与论文方法底稿

更新：2026-11-16。本文件是唯一维护的 KMC 方法说明。当前为无限 Ag 源、三态六事件、连续桥后演化及回零观察。首桥前保留已验证的形成模型，桥后使用修正后的局部电子库电势。

当前默认是诊断基线，并未完成联合拟合：seed 17 点末开启 1.320 V，全程 5 次几何断连，末 100 ms 逐事件电导极差 7.1080%。开启窗口候选和稳定性对照各有未通过项，详见第 10 节。单条曲线的开启位置对齐不能替代完整 I–V、随机分布与保持验证。

日常运行统一使用 `run_kmc.py`，全新 forming 从空白介质开始；历史首桥文件只用于形貌与读出诊断。原始 202 点 0→1.5→0 V、名义 20 ms/点、1 mA 限流，随后固定观察 200 ms 零偏压。首次反偏 RESET 与后续 SET/RESET 循环尚待实现，PINN 暂缓。

## 1. 无限 Ag 顶电极与格点

| 区域 | 数组行 | 当前定义 |
|---|---|---|
| 顶 Ag | 0 | 一行固定金属，电势为实际器件电压；无限源库边界 |
| 上层 AlN | 1–20 | 初始为空宿主 |
| 中层 AlScN | 21–40 | 初始为空宿主，含静态氮空位影响标记 |
| 下层 AlN | 41–60 | 初始为空宿主 |
| 底 Pt | 61 | 一行固定惰性金属，电势 0 |

当前横向 150 格、格距 1 nm，数组 **62×150**，介质总厚 60 nm。四邻接、横向绝缘。150 nm 是局部二维窗口宽度，不是整器件直径；一个占据格仍为有效 Ag 包，不是已经解析的单个原子。

“无限源”表示固定 Ag 边界通过源侧注入持续提供 Ag⁺，没有 4,200 包的电极库存上限，也不会把 30 nm 电极体逐格离子化。介质仍是一格至多一个有效包，受有限格点容量约束。新 forming 的初始介质没有预植入 Ag 丝。

占据态只有三种：0=空宿主，1=Ag⁺，2=金属。电极材料由边界位置识别，Pt 不注入 Ag，也不溶解。恢复后的源码不再使用吸附态 3 或有限 Ag 电极体。

## 2. 静电场、氮空位与位点能

首桥前沿用旧版介质场以保持已核对的形成路径；桥后继续演化时按第 10.2 节处理金属电势。贯通前方程为：

$$\nabla\cdot(\varepsilon_0\varepsilon_r\nabla\phi)=\nabla\cdot P,\qquad \mathbf E=-\nabla\phi.$$

当前恢复版本不包含离子空间电荷项。电压或金属构型变化后重求场；只发生离子跳跃时沿用当前场。AlN/AlScN 的相对介电常数为 8.5/15，材料面使用谐均值。首桥前 Pt 连通金属按阴极电势固定，浮置岛采用高介电近似。首桥后及后续再断开时，改用有限电阻网络的局部金属电势作为介质场边界；不会把贯通丝所有节点都设为 Pt 电势。

**AlScN 正向有效极化场仍与外加场同向。** 坐标 +z 从 Ag 指向 Pt，当前离散与边界约定下输入 P=−0.004 C/m²，未作反向修正。原解析场与符号检查已恢复并通过。

Ag⁺ 位点能为

$$G_i^+=U_i+\lambda m_i+\phi_i.$$

Ui 为标准差 0.025 eV 的固定无序，独立种子 811；mi 为固定缺陷影响标记，中层概率 0.15、缺陷种子 812，λ=0.05 eV。缺陷不等于金属占据，也不直接导电。正 λ 对离子进入、离开和还原的影响通过同一能差计算，不能仅据其符号判断最终是否促进成丝。

## 3. 恢复后的事件目录和能量差

当前保留旧版六类事件及首桥前能差；体扩散对应 `hop`，中性金属表面扩散对应 `migrate`。表中 φe 首桥前为 0，桥后按第 10.2 节计算。

| 事件 | 准入与变化 | 指定正向能差 |
|---|---|---|
| 注入 `inject` | 顶 Ag 下方第一层空宿主，0→1；固定 Ag 行保持金属 | ΔGin=Gi⁺−Vdev |
| 返回 `absorb` | 同一源侧格上的 Ag⁺，1→0，返回源库 | −ΔGin |
| 体扩散 `hop` | Ag⁺ 从 i 移到四邻空宿主 j | Gj⁺−Gi⁺ |
| 还原 `reduce` | 与 Pt 连通金属邻接的暴露表面，1→2 | ΔGred=μAg⁰−Ebind(i)−Gi⁺+φe(i) |
| 氧化 `oxidize` | 同一可逆暴露表面的 Ag⁰，2→1 | −ΔGred |
| 中性表面迁移 `migrate` | 暴露 Ag⁰ 移到四邻空宿主 | Ebind(i)−[Ebind(j)−J1] |

结合能 Ebind=J1 NAg+JPt NPt。四邻 Ag 键与 Pt 黏附均为 0.06 eV，μAg⁰=−0.10 eV。中性迁移目标结合能扣除源格尚在场时计入的最近邻键 J1。还原和氧化共用表面准入，完全埋藏格点不发生表面反应。

当前旧版的反应电子库来自 **Pt 连通金属表面**。顶 Ag 供给与返回由 inject/absorb 表达，而不是对有限电极体执行原位氧化。独立吸附/脱附、双端局部反应、经验阴极距离项和额外 0.40 eV 偏置不属于本次精确恢复的基线；后续若再加入，需在此基线上单项对照。

速率恢复为

$$k_f=\nu\exp[-(B+\max(\Delta G,0))/(k_BT)],\quad
k_r=\nu\exp[-(B+\max(-\Delta G,0))/(k_BT)].$$

冻结局部场与构型下，kf/kr=exp(−ΔG/kBT)。当前候选 ν=2.42×10¹² Hz，T=300 K；历史基线 ν=10¹³ Hz。ν 是有效包的动力学时间尺度，未被识别为实测原子频率。正逆使用同一基准势垒，下坡率不超过 ν。

| 参数 | 当前值 / eV |
|---|---:|
| AlN / AlScN 体扩散 | 0.48 / 0.50 |
| 跨材料界面附加项 | 0.025，先取两侧基本势垒平均 |
| 源库注入 / 返回 | 0.680 |
| 还原 / 氧化 | 0.52 |
| 裸 Pt 反应对附加成核势垒 | 0.08 |
| 中性 Ag 表面迁移 | 0.80 |
| Ag–Ag 键能 / Pt 黏附 | 0.06 / 0.06 |

上表为当前默认诊断基线的有效参数。历史开启标定仅改变统一 ν；第 10 节另比较了结合能与源交换势垒，尚未选出全部达标的新默认参数。所有能量均为有效模型量，不能直接解释为已测定的单原子势垒。

## 4. 随机抽样、源库账本和连通

总率 R=Σkr，等待时间 Δt=−ln(u1)/R，使用第二个随机数按 kr/R 选择事件实例。电压不变时，观察截止前未发生的待事件保留；电压改变后按新率重抽。

注入使净源供给 `net_source` 加 1，返回减 1；跳跃、氧化还原及中性迁移不改变内部 Ag 总数。因此：

$$N_{\rm Ag,inside}=N_{\rm inject}-N_{\rm absorb}=\texttt{net\_source}.$$

同时检查金属生成数 Nreduce−Noxidize 与内部金属数相配。顶 Ag 源库供给开放，但内部净流入账本闭合；不再使用有限电极的 Nmetal+Nion=4,200 公式。

只有中性金属的四邻路径同时连接上下边界，才记为首桥。离子云、对角邻接、背景漏电和短隧穿都不单独构成金属几何贯通。

`fast_kmc.py` 恢复原等价目录缓存：金属和电压不变时复用源、反应、迁移和各位点跳跃率，只按当前离子占据筛选。每个离子位移仍逐次抽样执行；当前没有四态模型的吸脱附批处理。

## 5. 电流与 forming 终止方式

金属/短间隙网络与经验背景漏电并联，负载线及 1 mA 限流求实际 Vdev，再反馈给当前场和速率。当前电子网络参数：金属电阻率 1.6×10⁻⁸ Ω·m，面外深度 1 nm，接触电阻 500 Ω，轴向隧穿间隙上限 2 nm，隧穿势垒 1 eV，外部串联电阻 100 Ω。

当前候选网络并联权重为 **1**，背景采用形貌参考的 sinh 支路（每列 10⁻¹² S，电压尺度 2 V）。这些电子参数在本轮开启标定中未重新拟合。早期试验曾采用其他电子缩放和背景函数，不属于当前配置。当前 I–V 全曲线仍有明显偏差，不能因开启位置对齐就判定电学拟合完成。

历史首桥参考采用形成后冻结形貌。按用户要求，当前默认使用原始 forming 的完整 202 点 0→1.5→0 V 波形，包含重复峰值；首桥后继续全部 KMC 事件。名义每点 20 ms、回环共 4.04 s，之后固定增加 0.20 s 零偏压观察。早期动态试验曾采用 0.10–0.20 s 自适应观察时长。20 ms 来自 50 Hz、假设 PLC=1，原始数据缺逐点实际时间戳。

当前已接通动态桥后生长与回零观察。首次反偏 RESET 和后续 SET/RESET 循环尚未执行；短时零偏压结果不等于长期保持试验。PINN 继续搁置。

## 10. 桥颈断连诊断与局部电子库修正（2026-11-16）

### 10.1 原因证据与修正范围

对第 9 节 seed 17 全程连通性日志逐项回查，288 次几何断连均对应金属数减 1 的氧化事件；未发现由中性迁移直接触发的断连。它定位了事件类别，未单凭数量确定每次断口的位置。进一步对同一首桥构型施加 1.35 V 作冻结形貌诊断，发现接近顶电极的关键格点（数组 row=1、x=74）存在本地电子库电势错误。

该格点的金属网络节点电势为 0.681625 V，而原邻居算术平均为 0.931625 V，额外引入约 0.250 V 的反应驱动力。原因是网络中的电极接触边电阻为 516 Ω，丝内相邻边为 16 Ω，算术平均没有使用这些电阻信息。在该固定构型、同一电压与其余同一参数下，原氧化率为 4,448.36 s⁻¹；使用本地节点电势后为 3.62172 s⁻¹。这个局部率比较不等于证明所有历史断连都发生于该点。

[关键格点电势和氧化率核查](../results/bridge_stability_20261116/critical_site_electron_potential_audit.json)。修正前源码和参数仅作为本次结果的可追溯快照保存于 [baseline_sources](../results/bridge_stability_20261116/baseline_sources/) 与 [baseline_settings.json](../results/bridge_stability_20261116/baseline_settings.json)，不作为第二套日常入口维护。

### 10.2 当前桥后电子库与计算公式

保留第 3 节的可逆局部能差和表面准入，只替换桥后电子库电势的求法：

$$\Delta G_{\rm red}(i)=\mu_{\rm Ag}^0-E_{\rm bind}(i)-U_i-\lambda m_i-\phi_i+\phi_e(i).$$

1. 若 i 已被金属占据，用已求解的金属电阻网络在该节点的电势，即 φe(i)=φmetal(i)。由于金属节点同时是介质场的固定边界，φi 与 φe(i) 在此处一致，不再由不等电阻邻居的算术平均产生虚假电势差。
2. 若 i 为待还原的 Ag⁺ 位点，用合格的四邻 Pt 连通金属构成一个虚拟电子节点。在保持邻居电势冻结的近似下，由该虚拟节点的 KCL 求加权电势：

$$\phi_e(i)=\frac{\sum_{j\in D(i)}g_{ij}\phi_{\rm metal}(j)}{\sum_{j\in D(i)}g_{ij}},\qquad
g_{ij}=\frac{1}{R_{\rm Ag}+\mathbf 1_{j\in\text{电极}}R_c}.$$

这里 D(i) 沿用原反应准入，不新增跨隧穿的电子供给。RAg=ρAg/dout=16 Ω，Rc=500 Ω；统一并联缩放因子在加权比中约去。虚拟节点是一次局部预测，还原实际执行后仍重求整个电阻网络与介质场。它不是提前插入金属路径。

氧化/还原仍使用同一 ΔG 的正反方向和原 Arrhenius 形式；冻结场和局部环境下率比保持 exp(−ΔG/kBT)。自洽场会随事件改变，因此这项代数检查不证明全局轨迹满足一个严格统一自由能的详细平衡。首桥前仍采用原场与原事件式；首桥后的局部电势修正本身不能缩小首桥电压的跨种子分散。

在同一零偏压构型中，旧、新电子库的电势均为 0。因此零偏压保持的变化应归因于前段演化形成了不同构型，以及结合能等参数的变化；本节诊断的接触电势误差直接作用于有偏压的桥后过程。

本轮没有增加焦耳热、电化学双电层或新的界面过电位模型。在已有金属位点 φi 与 φe(i) 抵消的当前近似中，氧化仍主要由化学位点能与配位结合能控制；负压 RESET 的场促溶解和热反馈必须另行建模验证，不能由本次正向 forming 稳定性测试宣称已经完成 RESET。

### 10.4 验证与版本边界

新增三项针对性的检查分别覆盖已有金属节点电势、待还原节点的接触电导加权、冻结环境下氧化还原率比；连同原检查共 **30 项通过**。[检查记录](../results/bridge_stability_20261116/unit_tests.txt)。四个历史形成核心模块保持不变，桥后修正位于 `dynamic_kmc.py`。

旧动态检查点仍保留，但由于物理源码校验值发生变化，不能直接用新版 `--resume` 续算；读取旧数组作只读比较不等于续算旧随机轨迹。新版从空白器件生成的新检查点可按当前入口继续，首桥筛选阶段与回环阶段保存、恢复同一 RNG 和待事件，不重新造丝。当前不取消版本校验，也不将历史检查点标记成新版计算。

新的完整回环验收同时核对：原始 202 个电压点、20 ms/点、1 mA 限流、两类 Ag 账本、首次几何桥、电学 0.5 mA 越阈值点、开启后平台、回零几何贯通，以及末 100 ms **全部金属事件**的电导相对极差≤5%。另行报告严格实验采样格：1.320 V 仍低于阈值、1.335 V 达到阈值；“数值在 1.320–1.335 V 内”与“完全对应这个采样格”不是同一个判据。原始仪器的积分整定时序未知，整步平均仅作明示假设的辅助对照。

### 10.7 后续优先验证的物理问题

下一阶段应同时考察最低配位连接的存活概率和最小有效截面，并用多条实验曲线约束开启分布。现有 1.320–1.335 V 是单条实验的采样区间，不能直接要求整个随机分布都落入同样的 15 mV 宽度。ν、有效势垒与名义积分时序存在辨识耦合，当前参数仍是拟合候选。

本轮保持了旧版上坡代价型速率，较大的有利驱动力也不会把同一基本事件率推到 ν exp(−B/kBT) 以上。后续可依据界面反应证据，单独检验局部场对过渡态势垒的影响，而不仅是继续缩放统一时间尺度；改动前须给出同一反应对的正逆能差、势垒与率比检查。它是待检验的建模方向，尚未实现，不能预称会使开启分布变窄。

形貌方面还需区分 Ag–Ag 结合、Ag–Pt 黏附及中性表面迁移对团簇并合与薄颈的影响；1 nm 有效包的一次氧化可显著改变一条支路的电导，后续应检查空间离散尺度的敏感性。负压 RESET/SET 循环所需的局部过电位、双端电子供给及可能的焦耳热仍是独立待验证内容，本次结果没有完成循环级拟合。
