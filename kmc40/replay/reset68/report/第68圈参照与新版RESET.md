# 以原 KMC 第 68 圈为参照的离散 RESET

目标取自原连续 KMC 的第 68 圈。原曲线在 −0.165 V 达峰，−0.240 V 首次降到半峰。随后既有小平台和短暂回升，也有离散的电流下降。新版已从原始初始化检查点跑完 100 个连续 SET–RESET 循环，默认页面打开新版第 68 圈与这条固定目标的对照。[单圈、局部放大与 100 圈叠加 HTML](reset68_comparison.html) · [连续 100 圈 SET 与 RESET 电流 CSV](../continuous/iv/iv_all.csv)

## 为什么改回离散事件

原第 68 圈的峰后前段是两个瓶颈格点先后退缩。−0.165 至 −0.270 V 的端电导下降 0.884 个数量级，按逐事件冻结电子态的归因，约 97% 来自 Ag 几何变化。断桥后，撤去某个 Ag 格可能削弱旁路，也可能露出先前被金属覆盖的氮空位，暂时提升缺陷辅助电导。例如，−0.375 V 的一个事件使读电导从 239 升到 299 µS；在同一形貌、相同电子态下只关闭该格新露出的氮空位，电导降至 180 µS。到 −1.185 至 −1.500 V，电子缺陷活性的衰减贡献了端电导降幅的约 84%。这些证据来自模型逐事件的空间状态与电路复算。[原第 68 圈形貌与事件归因](original68_mechanism.md)

新版恢复了逐位点氧化、Ag 回流与金属／隧穿／缺陷网络读出。首次失去金属贯通后，局部电子交换和 Ag 离子输运能力可以成为瓶颈。模型假定，当时已经启动且仍在排程的颈部位点共享原先一个位点的退缩通量。若有 m 个位点在途，每个位点以原速率的 1/m 推进；一个位点完成后释放其份额。每个离开格点的 Ag 微步仍须通过实际可用的回流路径。全部调度使用当下形貌和事件状态，无需输入目标曲线或逐圈拟合参数。

这个通量上限是待验证的有效动力学假设。它不要求所有离子沿同一条格点路径返回。原 C68 在断桥时有两个在途位点，两条当时采用的路线共享一个路径格。C100 有五个位点，十对路线中只有一对共享路径格。因此 C100 的改善不能单独证明存在一条唯一的物理回流通道。52 个循环在断桥时有至少两个在途位点，其余循环的这一调度改动没有实质作用。[模型实现和消融对照](reference/kinetics.md)

## 连续第 68 圈的结果

所有数值均直接取自 15 mV 原始采样间隔的驻点平均电流。中段取负向去程的 |V| = 0.30–1.20 V，共 60 次相邻采样变化。下降超过 0.030 dec 计作一次明显降阶，上升超过 0.005 dec 计作一次回升，绝对变化不超过 0.005 dec 计作近平台。dec 为十进对数电流单位。

| 去程特征 | 目标：原 KMC C68 | 上一版平滑模型，同一初态 | 新版连续 C68 |
|---|---:|---:|---:|
| 峰位（V） | −0.165 | −0.405 | −0.165 |
| 峰值电流幅值（mA） | 0.502 | 1.069 | 0.502 |
| 首次下降到半峰（V） | −0.240 | −0.720 | −0.240 |
| 最大单步降幅（dec） | 0.149 | 0.030 | 0.149 |
| 中段明显降阶数 | 17 | 0 | 17 |
| 中段近平台数 | 20 | 5 | 21 |
| −1.500 V 电流幅值（µA） | 1.515 | 48.925 | 1.515 |

新版保留了原 C68 四次中段小回升中的三个，去程对原 C68 的逐点对数电流 RMSE 为 0.0016 dec。第 68 圈在相同初态、相同空间随机过程下比较，新调度主要涉及两个尚未退缩完的位点，因此此处的接近程度不是对其他初态的独立预测精度。[原始比较](reference/baseline_comparison.csv) · [新版逐圈结果](continuous_metrics.csv)

## 一百圈能推广到什么程度

将每条模拟曲线的 100 个非零去程电流点与固定原 C68 比较，不平移电压，也不归一化电流。误差中位数在上一版平滑模型为 0.939 dec，在原离散 KMC 为 0.330 dec，在新连续链为 0.328 dec。新版 100 圈中有 16 圈的 RMSE ≤ 0.20 dec，原离散 KMC 有 15 圈，其中包括目标自身，上一版平滑模型为 0 圈。新版主要恢复了原模型的离散形态，额外的通量共享对部分初态有局部改善。第 100 圈的去程误差为 0.352 dec，原模型为 0.447 dec，中段明显降阶数从 4 次增至 8 次；第 57 圈的去程误差仍达 0.725 dec。[各圈分布统计](paired_distribution.csv)

连续计算中，每个 SET 都继承上一 RESET 的 Ag、缺陷电子态和随机数状态。13 个 SET 的输入完全相同，可直接复用既有结果；其余 87 个 SET 重新积分，100 个 RESET 均以新版调度积分。这条轨迹中，每个阶段终点恰好仍对应原空间目录的同一事件前缀，空间目录得以复用。独立从 100 个旧 SET 末态起算的配对 RESET 与新连续链的 20,200 个 RESET 电流点逐点相等，两份结果属于同一空间随机轨迹。全部 200 个阶段均核对了继承关系和 Ag 守恒。[连续链核对表](../continuous/chain_summary.csv) · [最终连续 100 圈 I–V CSV](../continuous/iv/iv_all.csv)

另外检验了增强界面缺陷跃迁与改变断桥后氧化位点选择的假设。单纯降低邻近氮空位的有效势垒 0.035 eV 后，C68 的半峰推迟到 −0.270 V，去程 RMSE 增至 0.191 dec。改变氧化位点选择可以改善部分困难初态，却也会放大其他初态的单步突降。这些试验保留为备选对照；默认连续链使用无新增拟合参数的在途通量共享。[界面势垒试验](reference/interface35_c68.json) · [改变位点选择的跨初态对照](reference/spatial_transfer.csv)
