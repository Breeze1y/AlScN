# 共享剩余通量模型的 100 圈连续 SET–RESET 轨迹

从原始 [INIT_RESET 检查点](../../../results/cycle_reset_fit40/mid_clock_set/INIT_RESET/checkpoint/) 开始，按 SET → RESET 的顺序完成 100 圈。每相读取直接前一相的 Ag 身份与占位、VN、累计银量、电子状态、随机数状态。各相用原电压协议的 202 个采样点，每个采样点积分 16 个子步。全局起止时间约为 404 至 40804 个有效驻留单位，尚无秒的独立标定。

- [100 圈 IV CSV](iv/iv_all.csv) 含 40,400 条记录，依时序存放 SET 和 RESET、有符号电压、驻留平均电流、采样端点电流、全局时间和端点读电导。零电压、转折点及重复电压均保留。
- [连续性与逐圈摘要](chain_summary.csv) 包含两相电阻、Ag 体积、事件数、时间、空间目录来源，以及与原轨迹的终态几何、随机数、电子状态比较。
- 每圈两相的 `states.npz` 保存全部采样点的形貌与电量。RESET 的 `events.csv`、`actual_transport.npz` 和 `snapshots.npz` 保存实际体积动作、回流路径和关键快照。例如[第 68 圈 RESET](cycle_68/RESET/) 及[第 100 圈 RESET](cycle_100/RESET/)。

**真实继承与复用。** 第 1–13 圈 SET 的全部输入和原模型完全相同，故直接复用这些已求解的 SET。第 13 圈 RESET 结束时电子状态首次与原链出现差异，第 14–100 圈的 SET 均重新求解。100 圈的 RESET 全部采用新调度实时求解。每个新相启动时比较了 Ag 标识、VN、累计银量、随机数和空间生成参数；这次实际运行的全部 200 个空间起点恰好都允许复用原空间事件目录。相同的空间事件前缀确定同一终点随机数，电子态和观察时钟则来自本次连续求解。所有 200 个相终点的 Ag 几何及随机数与原空间链相同。52 圈在首次断桥瞬间至少还有两个已经启动的局部退缩站点。

**完整性。** 验证了 200 个相的检查点衔接、端点 Ag/VN、202 帧的 Ag 质量守恒、电子态继承和每个相的起始随机数。所有 RESET 回到 0 V 时均无待执行微步。第 68 圈的峰位为 −0.165 V、峰电流绝对值为 0.5024 mA，相对原第 68 圈的外扫 log 电流 RMSE 为 0.00162 dec；第 100 圈为 0.35155 dec。该比较的参照为原 KMC 第 68 圈。

在项目根目录运行以下命令，可从现有相检查点继续。此次先完成了第 1–3 圈的衔接检查，再续算至 100 圈。

```powershell
.venv\Scripts\python.exe scripts/run_reset68_continuous.py --cycles 100
```
