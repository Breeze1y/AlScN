# KMC40 连续 100 圈仿真总结

40 nm AlScN 模型的 100 圈轨迹中，每圈 SET 回零时均存在贯穿薄膜的 Ag 通路，每圈 RESET 回零时通路均断开。逐圈 RESET/SET 末态读出电阻比的中位数为 **4.26 × 10³**。

## IV 与形貌

- [100 圈独立 IV CSV](iv_all.csv)含 40,400 条记录。每圈有 SET 和 RESET 两段，每段 202 个采样点，按圈号、阶段、采样点和去程或回扫标记。`voltage_V` 为施加电压，`current_A` 为驻点平均电流，`endpoint_current_A` 为驻点结束时的电流。电流列保留原始符号和零值。
- [100 圈 IV 叠加与末态电阻](iv_100cycles.pdf)用对数轴显示非零的驻点平均电流绝对值。第 100 圈以彩色突出，实线为去程，虚线为回扫。[PNG](iv_100cycles.png) · [SVG](iv_100cycles.svg)
- [100 圈 SET/RESET 末态形貌图册](morphology_100cycles.pdf)含 200 个回零末态和一页代表性圈次比较。每幅图视场为 50 × 40 nm，网格间距为 0.5 nm。蓝绿色标示贯通 Ag，棕色标示其余 Ag，浅灰色标示 N 空位。[形貌预览](morphology_overview.png)

## 结果

| 指标 | 100 圈范围 | 100 圈中位数 | 第 100 圈 |
| --- | ---: | ---: | ---: |
| SET 末态读出电阻（Ω） | 137.3–295.9 | 262.2 | 238.4 |
| RESET 末态读出电阻（MΩ） | 0.660–1.118 | 1.118 | 1.118 |
| RESET/SET 末态读出电阻比 | 2.82 × 10³–8.14 × 10³ | 4.26 × 10³ | 4.69 × 10³ |
| 首次贯通的 SET 采样电压（V） | +0.300 至 +0.360 | +0.345 | +0.345 |
| 首次断开的 RESET 采样电压（V） | −0.375 至 −0.045 | −0.270 | −0.285 |

第 1–10 圈的 SET 末态 Ag 体积中位数为 828 个粗粒化体积单位，第 91–100 圈为 528 个。同期 SET 末态读出电阻的中位数从 152.6 Ω 升到 272.2 Ω，后十圈 SET 末态仍全部保持贯通。第 100 圈 SET 和 RESET 末态的 Ag 体积分别为 531 和 443 个粗粒化体积单位。

## 运行与核验

用项目 `.venv` 的 Python 3.14.5 和锁定依赖运行 `run_100_cycles.py`。前 5 圈沿用 `mid_clock_set`，第 6–100 圈从第 5 圈 RESET 检查点连续演化。

原脚本在第 16 圈 RESET 遇到暂时堵塞。经确认后启用等待机制，受阻的氧化事件在目录阈值处暂停，受阻的微步恢复后按原间隔执行该格点的后续微步。每次 Ag 移除都校验通往顶端储库的空回流路径。第 16、29、58、62、64 圈各发生一次等待，时长为 2.53–13.27 个有效驻留单位。

脚本以退出码 0 完成。全部 40,400 条 IV 记录与各阶段的原始 CSV 和 NPZ 逐点一致。全部 200 个阶段通过首末 Ag 形貌续接、Ag 守恒和末态贯通状态核对。两份 PDF 通过字号和版面碰撞检查。
